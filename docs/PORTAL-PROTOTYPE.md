# Portale Emme Studio — prima fase

Demo statica con dati inventati: `portal-preview.html`, `portal.css`, `portal.js`.

## Flusso verificabile

Panoramica → aprire Mix v2 → scrivere un commento → richiedere revisione oppure approvare → dashboard, stato del brano e attività aggiornati. Gli aggiornamenti della demo sono memorizzati soltanto nel browser; ripristino disponibile.

## Comprende

Dashboard, scheda progetto, due brani di esempio, stati attività, calendario dimostrativo, storico commenti e approvazioni. Nessun file reale, account, email, evento esterno o pagamento.

## Fase successiva dopo revisione

Definire utenti e matrice dei permessi (amministratore, team, artista, collaboratore), responsabilità di approvazione, modello dei progetti/brani/versioni, archivio file e limiti degli upload. Implementare autenticazione e controlli server per isolare i progetti. Successivamente aggiungere notifiche, calendario reale ed eventuale gestione economica.

La demo è accessibile sul branch e non costituisce un'area riservata sicura. Non inserire dati o materiali reali in questo prototipo. Nessun link è stato aggiunto alla navigazione del sito pubblico.
