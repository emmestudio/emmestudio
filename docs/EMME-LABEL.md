# Emme Label

Manage artist profiles and releases in the studio portal under Emme Label · Sito.
The public site reads published entries from /api/public/label and uses the order
saved in the portal. The roster and releases are ordered separately.

Artist pages use label-artista.html?artista=SLUG. Moody retains the existing
address label-moody.html. Artist and release Spotify players load on request.
